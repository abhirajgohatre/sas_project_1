# SAS Project 1

A beginner-level clinical SAS programming project.

## Project Overview

This project demonstrates basic understanding of clinical SAS programming by generating CDISC-compliant datasets. It includes:
- Demographics data for 100 individuals
- Adverse events data for 100 individuals

This is a learning/trial project to practice SAS programming fundamentals.

## Files Included

- Demographics dataset
- Adverse events dataset

## How to Run

1. Update the data path in the SAS scripts
2. Run the SAS programs in order
3. Check the output datasets in the output folder
